## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage

## Cómo ejecutar el proyecto

Abrir el archivo `index.html` en un navegador web. También se puede ejecutar utilizando Live Server desde Visual Studio Code.

## Funcionalidades implementadas

- Página principal con navegación.
- Catálogo de productos.
- Vista de detalle de cada producto.
- Carrito de compras.
- Agregar, eliminar y modificar la cantidad de productos del carrito.
- Cálculo del total del carrito.
- Registro de usuarios mediante LocalStorage.
- Inicio de sesión simulado mediante LocalStorage.
- Almacenamiento del carrito mediante LocalStorage.

## Funcionalidad diferenciadora

Filtros de productos por:

- Edad.
- Número de jugadores.
- Duración.
- Categoría.
